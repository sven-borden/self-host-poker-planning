The crux · D1 to D4

One build, three places to run it

Coolify and Azure keep a container alive for days. Vercel runs functions: since 22 June 2026 they accept WebSockets (public beta), but each socket stays pinned to the instance that took it and is closed after 300 s on Hobby or 800 s on Pro. Two people in the same room can land on different instances. The design keeps room state in Postgres and makes the event bus swappable, so the same code runs in all three places.

Coolify

  • One image, one Postgres resource
  • Auto-deploy from main
  • Your own instance first (like Popote)

Azure

  • Container Apps, scale 1 by default
  • Postgres Flexible Server, Burstable tier
  • SQLite avoided: Azure Files locking

Vercel

  • Rides the WebSocket beta: proven by a spike in W0
  • Hobby plan is non-commercial; companies need Pro
  • Clients reconnect at the time limit and resync
How a round works · D10 and D11

The server owns the round

Every command goes through one pure function, apply(state, command), that returns the new state and the events to send. Server, tests and the client’s optimistic UI share it. Before reveal, other people only learn that someone voted, never the value.
