- **#10 (PP-010) merged, PR #74.** Identity with Better Auth 1.7.13: the anonymous
  plugin and the Drizzle adapter, on `pg`.
  - **Guests and cookies.**
    - A first visit creates a guest.
    - The session cookie is httpOnly, `SameSite=Lax` and path `/`.
    - On https it is `__Host-pp.session_token`: Secure, with no Domain, so a sibling
      `*.borden.ch` site cannot plant one.
    - On http it has a plain name and no Secure flag, so a self-host on a LAN still
      works.
    - Sessions last `ROOM_TTL_DAYS` after the last visit, refreshed at most once a day.
  - **API surface.**
    - Only `get-session`, `sign-in/anonymous` and `sign-out` are exposed under
      `/api/auth`. Every other path there gets a JSON 404 before the rate limiter.
    - Bodies on `/api/*` are capped at 16 KB.
    - Better Auth's English messages and its own codes are mapped to our codes, and no
      JSON answer carries a token.
    - Our own Origin check guards the auth POSTs and `/api/me/name`.
  - **Display names.** `POST /api/me/name` cleans the name with the domain's
    `cleanName`.
    - It now refuses invisible and bidi control characters: zero-width characters,
      soft hyphens, tag characters outside emoji, and the Hangul filler.
    - It also refuses a name that is blank after cleaning.
    - W1 renders names inside `<bdi>`.
  - **Sockets.** The Socket.IO middleware reads the session from the handshake cookie
    and sets `socket.data.user`. A socket without a valid session is refused with
    `unauthenticated`.
  - **Proxies and limits.**
    - `TRUST_PROXY` is now a proxy count from 0 to 10.
    - Anonymous sign-in allows 60 per address per minute, so an office behind one
      address can join together.
    - Behind Sven's Synology and Traefik the count only helps once Traefik trusts the
      Synology.
  - **Privacy.**
    - Sessions store no IP address and no user agent.
    - Better Auth's telemetry is off.
    - Tokens never reach logs, stdout or stderr, even when the database fails. A test
      captures all output to check it.
  - **Web.**
    - `ensureIdentity()` shares one request between concurrent calls. A Web Lock spans
      tabs, so two tabs on a first visit become one guest.
    - After a redeploy it retries with backoff.
    - It shows a clear message when cookies are blocked.
    - Typed `fetch` calls replace `better-auth/client`, saving 12.4 kB. The room route
