- **#1 (PP-001) merged, PR #61.**
  - The pnpm workspace has four packages: `apps/web`, `apps/server`,
    `packages/domain` and `packages/protocol`.
  - TypeScript 7.0.2 is strict, with project references (`tsc --build`),
    `moduleResolution: bundler` and `.ts` import extensions.
  - Tools: Biome 2.6.3; Vitest 5.0.5 with one project per package plus `scripts` and
    `db`; Vite 8.3.5; tsdown 0.23.2, which bundles the server and inlines `@pp/*`.
  - Node 24 is enforced twice: `engines` with `engineStrict`, and
    `scripts/check-node.mjs`. Both refusals were checked under a real Node 22 in Docker.
  - The review found that pnpm 11.1.2 has 17 advisories, so pnpm 12.15.0 is pinned.
    That version also makes `pnpm deploy` work for #11.
  - Other review fixes: `*.db.test.ts` stays out of the unit projects, `test:db` runs one
    file at a time, and the server starts with source maps.
  - There is no CI yet (#2) and nothing is deployed (#12), so the gate ran locally on
    fresh clones.
- Notes for later issues, from the review of #61:
  - #8: Biome needs `css.parser.tailwindDirectives: true` for Tailwind v4 (`@theme`,
    `@custom-variant`), and TanStack's generated `routeTree.gen.ts` must be excluded
    from Biome.
  - #8: TypeScript 7 rejects `baseUrl` (TS5102). shadcn's `@/*` alias therefore goes
    in `paths` without `baseUrl`, in both `apps/web/tsconfig.json` and
    `tsconfig.app.json`.
  - #8: the `web` Vitest project must extend `apps/web/vite.config.ts`.
  - Windows: pnpm 12 writes `node_modules/.pnpm-task-run-state-v1/…` files. Keep a
    clone path under about 130 characters, or `pnpm build` fails.
- **#2 (PP-002) merged, PR #62.** `.github/workflows/ci.yml` runs on pull requests only,
  with no branch filter.
  - Two jobs run in parallel on `ubuntu-26.04`. `check` runs `pnpm gate`; `db-tests` runs
    `pnpm test:db` against a `postgres:17` service.
  - Docs-only and Markdown-only changes are skipped by `paths-ignore`.
  - The concurrency group is scoped to the workflow and the PR. Actions are pinned by
    commit SHA, and the SHAs were verified against their release tags.
  - A placeholder `apps/server/src/db-reachable.db.test.ts` checks that Postgres is
    reachable until #7.
  - The acceptance criteria were proven with two throwaway draft PRs, closed unmerged:
    #63 (a lint error fails `check`) and #64 (a docs-only change starts no run).
  - Review fixes: `test:db` no longer passes with zero tests, checkouts drop their
    credentials, and Biome skips Markdown.
  - CI was watched by a background `gh pr checks --watch`, which costs no model tokens.
