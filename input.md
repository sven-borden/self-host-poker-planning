# Self hosted Poker Planning

The application is a self hosted poker planning platform. Allowing us to deploy in vercel or coolify or azure instances quickly and easily. 

The application will be created because we do not have something well done to support it

## Requirements

- We should be able to create an account with Microsoft or Google (in the latest waves)
- We should be able to use the tool without any account
- Each "room" will be a dedicated link, that we can protect with a password for example if needed
- a room can handle up to 16 people
- a room will have a "product owner" (admin)
- we should have settings in place to handle a few situations. A link we estimate, nothing, just a round, the estimates values, timer to vote, etc
- Timer to vote, reveal the cards at the end of the timer or not (setting)
- Estimates should be free or a few sets already exists. tshirt size, fibonnacy, numbers, increments. 
- we should have specific cards like question mark and coffee for the estimates that could be used
- it should be live (pocketbase?)
- each user joining a room can set a name
- a nice to have feature at a later stage is to have small animated svg avatars to choose from
- we should have a history of the rounds that were estimated in the past
- the product owner can reveal the cards (force)
- we should have the choice to reveal who voted what, or just see the number of cards
- we should have a summary of what is proposed
- an optiuon should exist to be able to edit a vote after the cards have been revealed
- design should be efficient and professional. probably oriented around a table
- later we would like to get a connector or an easy paste from Jira/ADO tickets to fill up the backlog of estimation quickly
- we should have top notch animations when we have cards. 
- at a later stage, we should have the option to brand the application, or the cards with company name or other things. this would be with a price. the base functionalities should be free
- we should have some music background available when we wait for the vote for example (later stage)
- we should support light and dark mode
- it should work on mobile too
